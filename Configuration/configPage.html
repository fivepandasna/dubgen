Dubtitles

Sends the English audio track of foreign-language media to Subgen and saves the result as <title>.en.Dubtitles.srt next to the media file. Run it from Dashboard → Scheduled Tasks → Dubtitles → Generate Dubtitles (default: daily at 02:00).

Subgen

Base URL, e.g. http://192.168.1.50:9000 (no trailing /asr).

Libraries

Tick the libraries to process. Leave all unticked to process every library. Useful for running only on e.g. an Anime library and skipping Movies / Shows.

Skipping

Off: only episodes/movies that already have a Dubtitles file are skipped, so a half-finished series resumes where it stopped. On: the rest of that series is left alone.
0 = no limit.

Output

Produces Title.en.<tag>.srt. Default: Dubtitles.

Before run webhook

Sent once, only when there is something to process, before anything goes to Subgen. Use it to wake or start a remote machine.
Sent as "Authorization: Bearer <token>". Leave empty for none.
If Subgen never comes up, the run is aborted (the after-run webhook still fires).

After run webhook

Sent when processing ends — finished, failed or cancelled — but only if there was work to do. Use it to shut the remote machine down again.
Stored unencrypted in the plugin's config file on the Jellyfin server.
